## 四、技术栈与部署（详见 `docs/01`）

- 前端：Vue 3 + Vite + Pinia + Vue Router + Element Plus + ECharts
- 后端：Node.js + Express + better-sqlite3
- 数据库：SQLite 单文件 `data/invest.db`（WAL 模式）
- 部署：Docker + docker-compose，数据卷挂 `./data` 实现持久化
- 鉴权：JWT + bcrypt；邮箱验证码走 SMTP（管理后台可配、可测连通性）
