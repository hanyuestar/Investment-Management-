## 1. 系统总览

### 1.1 一句话
一个以"**真实收益**"为核心的自部署投资账本：记录四类资产、双币种、多账户，按交易时汇率锁定成本，支持做 T/分红/送股/拆分与摊薄+FIFO 双口径；在此之上提供**投资者真正需要的决策能力**——XIRR 年化、基准对比、资产配置再平衡、风险集中度、税务估算、定投与预警。

### 1.2 定位演进
```
v1–v3：「优秀的账房先生」——账算得准
v4  ：「账房 + 军师 + 风控 + 税务官」——让用户看清
      我到底赚了多少（XIRR）、跑赢没有（基准）、风险多大（集中度）、该不该调（再平衡）、要交多少税（税务）
```

### 1.3 角色
| 角色 | 说明 |
|---|---|
| 普通用户 | 注册/登录后管理自己的账户、资产、交易、汇率、报表、配置、预警 |
| 管理员 | 系统内置：全局汇率、邮箱服务器、用户管理（禁用/重置密码） |

### 1.4 技术栈
| 层 | 选型 |
|---|---|
| 前端 | **Vue 3** + Vite + Pinia + Vue Router + Element Plus |
| 图表 | **ECharts**（净值曲线 / 柱状 / 饼图 / 环形） |
| 后端 | **Node.js** + Express（或 Fastify） + better-sqlite3 |
| 数据库 | **SQLite** 单文件 `data/invest.db`（WAL 模式） |
| 鉴权 | JWT + bcrypt；邮箱验证码走 SMTP |
| 定时任务 | node-cron（汇率拉取、定投生成、快照、预警扫描） |
| 汇率源 | 主 Frankfurter（ECB）/ 备 open.er-api.com |
| 部署 | **Docker + docker-compose**，卷挂 `./data` |

## 3. 数据模型（SQLite 建表）

> 原则：**不存算好的结果**。成本、盈亏、收益率、税负全部由 `event` 实时计算——保证口径可切换、数据可追溯。

```sql
PRAGMA journal_mode = WAL;

-- 用户
CREATE TABLE user (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  username      TEXT    NOT NULL UNIQUE,           -- 唯一，不重名
  email         TEXT    NOT NULL UNIQUE,
  password_hash TEXT    NOT NULL,                  -- bcrypt
  role          TEXT    NOT NULL DEFAULT 'user',   -- user | admin
  status        TEXT    NOT NULL DEFAULT 'active', -- active | disabled
  created_at    TEXT    NOT NULL,
  last_login_at TEXT,
  settings_json TEXT    DEFAULT '{}'               -- 个人偏好：成本口径/目标配置/税务规则/基准
);

-- 邮箱验证码（登录用）
CREATE TABLE login_code (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  email      TEXT NOT NULL,
  code       TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  used       INTEGER NOT NULL DEFAULT 0
);

-- 账户（券商/银行）
CREATE TABLE account (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id    INTEGER NOT NULL REFERENCES user(id),
  name       TEXT NOT NULL,
  kind       TEXT NOT NULL DEFAULT 'broker',  -- broker | bank | other
  currency   TEXT NOT NULL DEFAULT 'CNY',
  note       TEXT,
  created_at TEXT NOT NULL
);

-- 资产
CREATE TABLE asset (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id      INTEGER NOT NULL REFERENCES user(id),
  account_id   INTEGER NOT NULL REFERENCES account(id),
  name         TEXT NOT NULL,
  code         TEXT,
  market       TEXT,                       -- CN | US（股票）
  type         TEXT NOT NULL,              -- stock | fund | wealth | bond
  currency     TEXT NOT NULL,              -- CNY | USD
  price        REAL DEFAULT 0,             -- 股票最新价
  market_value REAL DEFAULT 0,             -- 非股票当前市值
  alerts_json  TEXT,                        -- {takeProfitPrice,stopLossPrice,takeProfitRate,stopLossRate}
  created_at   TEXT NOT NULL
);

-- 交易与现金流统一事件表
CREATE TABLE event (
  id        INTEGER PRIMARY KEY AUTOINCREMENT,
  asset_id  INTEGER NOT NULL REFERENCES asset(id),
  date      TEXT NOT NULL,
  kind      TEXT NOT NULL,   -- buy|sell|div|bonus|split|invest|redeem|income
  side      TEXT,            -- buy|sell|div|bonus|split（股票）
  qty       REAL,            -- 份额（v5 起股票/基金/理财/债券通用；含 opening 期初建仓）
  price     REAL,            -- 成交价
  amount    REAL,            -- 金额（分红/投入/赎回/利息）
  ratio     REAL,            -- 拆分/合股比例
  fee       REAL DEFAULT 0,  -- 手续费/佣金（含一切卖出税费）
  fx        REAL NOT NULL DEFAULT 1,  -- ★记录时锁定的汇率（USD→CNY）
  note      TEXT
);
CREATE INDEX idx_event_asset ON event(asset_id, date);

-- 汇率时间线（手动 + 自动）
CREATE TABLE fx_rate (
  id     INTEGER PRIMARY KEY AUTOINCREMENT,
  date   TEXT NOT NULL,
  rate   REAL NOT NULL,               -- 1 USD = ? CNY
  source TEXT NOT NULL DEFAULT 'manual', -- manual | auto
  note   TEXT,
  UNIQUE(date, source)
);
-- 取数：date <= today 的最近一条；同日期 manual 优先于 auto。

-- 月末快照（用于含浮动月/年收益、TWR、基准曲线）
CREATE TABLE snapshot (
  id      INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES user(id),
  month   TEXT NOT NULL,        -- YYYY-MM
  total   REAL NOT NULL,        -- 当月末【持仓市值】（¥，不含账户现金）
  UNIQUE(user_id, month)
);

-- 基准点位（沪深300 等）
CREATE TABLE benchmark (
  id      INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES user(id),
  code    TEXT NOT NULL DEFAULT 'CSI300',
  date    TEXT NOT NULL,        -- YYYY-MM
  value   REAL NOT NULL,
  UNIQUE(user_id, code, date)
);

-- 出入金（账户级本金搬运）
CREATE TABLE cash_flow (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id    INTEGER NOT NULL REFERENCES user(id),
  account_id INTEGER NOT NULL REFERENCES account(id),
  date       TEXT NOT NULL,
  kind       TEXT NOT NULL,     -- deposit | withdraw
  amount     REAL NOT NULL,     -- 原币
  fx         REAL NOT NULL DEFAULT 1,
  note       TEXT
);

-- 定投计划
CREATE TABLE dca_plan (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id     INTEGER NOT NULL REFERENCES user(id),
  asset_id    INTEGER NOT NULL REFERENCES asset(id),
  start_month TEXT NOT NULL,     -- YYYY-MM
  months      INTEGER NOT NULL,
  day         INTEGER NOT NULL DEFAULT 15,
  amount      REAL NOT NULL,
  note        TEXT,
  active      INTEGER NOT NULL DEFAULT 1,
  created_at  TEXT NOT NULL
);
```

## 4. 核算与计算引擎（核心）

> 参考实现见 `server/calc.js`，测试见 `server/calc.test.js`（**49 项全绿**）。以下为口径定义，开发须严格对齐。

### 4.1 成本口径（可切换）
| 口径 | 规则 | 卖出结转 |
|---|---|---|
| **摊薄加权平均（默认 `wavg`）** | 成本总额累加，卖出按**卖出前摊薄均价**结转 | 做 T 成功→成本总额下降、摊薄价降低 |
| **FIFO（`fifo`）** | 按买入批次先进先出 | 卖出结转**最早批次**成本 |

**分红开关** `dividendReducesCost`：
- `false`（默认）：现金分红**计入已实现收益**，成本不变
- `true`：分红**冲减成本**，成本总额下降，不计已实现

### 4.2 双币种
- 基准货币 CNY；USD 资产 `fx` 逐笔锁定。
- **成本**用历史锁定汇率；**市值**用最新汇率；差额内含汇损，即"真实收益"。
- 人民币资产汇率恒为 1。

### 4.3 绩效指标族 ★v4
| 指标 | 公式 | 说明 |
|---|---|---|
| **XIRR（主指标）** | 解 `Σ CFᵢ/(1+r)^(dᵢ/365) = 0` | 资金加权年化；**分批投入时唯一公平的年化** |
| **TWR** | `Π(期末值/(上期末值+当期证券净投入)) − 1` | 时间加权，剔除买卖/申赎影响；需月末快照（持仓市值口径） |
| **简单年化** | `(1+账户口径累计收益率)^(365/持有天数) − 1` | 仅供参考 |
| **累计收益率** | 账户口径：账户收益 / 累计投入（= 净入金 + 期初建仓本金） | 简单口径 |
| **持仓口径收益率** | 持仓收益 / 期末证券净投入 | 投资能力口径 |

**组合现金流构造** `portfolioFlows()`：
买入/投入 = 流出(负)，卖出/赎回/分红/利息 = 流入(正)，**期末持仓市值 = 末期流入（terminal）**；按日期升序；若首笔为上流入，前插 `-1e-6` 占位保证 IRR 有解。

### 4.4 资产配置再平衡 ★v4
- 目标比例 `allocTargets`（默认 股60/基20/理15/债5）。
- 输出每类：当前市值、当前占比、目标占比、目标金额、**需调整额**（正=买入，负=卖出）。
- **偏离度** = `Σ|diff| / 2`（半总，等价于需调入总额）；>5% 提示再平衡。
- 生成**调仓清单**（只给建议，不自动交易）。

### 4.5 集中度风控 ★v4
| 指标 | 默认阈值 |
|---|---|
| 最大单一持仓占比 | 20% |
| 前 5 大持仓合计 | 60% |
| 股票类占比 | 70% |

超阈值 → 生成告警文案。**止盈止损预警** `checkAlerts()`：按 `takeProfitPrice`/`stopLossPrice`/`takeProfitRate`/`stopLossRate` 比对现价或收益率。

### 4.6 税务估算 ★v4（默认规则，可配）
| 项目 | 规则 |
|---|---|
| **A股 现金分红红利税** | 持股 ≤1月 **20%**；1月~1年 **10%**；>1年 **0%**（按除息日与首笔买入间隔判定） |
| **美股 股息预扣税** | **30%**（中美税收协定可降 10%） |
| **资本利得税** | A股个人 **0%**；美股非居民通常 **0%**（默认，可改为 15%） |
| 输出 | 分红逐笔明细（含税率/应缴/税后）、按市场按年已实现利得与预估税、**总税负** |

> ⚠ 界面须标注"**估算，非申报依据**"。

### 4.7 定投 ★v4
`dcaGenerate(plan)`：按月生成 N 期投入事件（`kind='invest'`），日期 = 每月指定日；一次性批量入库，可逐条删改。仅基金/理财/债券（股票逐笔录入）。

### 4.8 出入金 ★v4
`accountCash()` / `cashFlowSummary()`：账户现金余额与累计入金/出金/净入金。**关键作用**：本金搬运本身不产生盈亏（避免把追加本金误算成盈利），但 v5 起它计入**账户现金余额**与**累计投入**，并作为 **XIRR 的唯一外部现金流**。

## 5. 鉴权（v3 已定）

### 5.1 注册
- 邮箱 + 用户名 + 密码；**用户名唯一**；邮箱唯一。
- 密码 bcrypt（cost≥10）；正则与长度前端+后端双重校验。

### 5.2 登录（双方式）
1. **用户名 + 密码** → 校验 bcrypt → 签发 JWT。
2. **邮箱验证码** → 生成 6 位码存 `login_code`（5 分钟有效、一次性）→ 发信 → 校验。

### 5.3 会话与拦截
- JWT 默认 7 天；`Authorization: Bearer <token>`。
- 中间件校验：token 有效 + `user.status='active'`；**禁用用户即时失效**（每次请求查 status，或短 TTL 缓存）。
- 路由：`/api/auth/*` 公开，其余需登录，`/api/admin/*` 需 `role='admin'`。

## 6. 管理后台（v3 已定）

### 6.1 汇率管理
- 展示汇率时间线（✍手动 / ⟳自动，来源徽章）。
- **手动录入**：日期 + 汇率 + 备注（`source='manual'`）。
- **立即同步**：调主源失败自动降级备用源。
- **优先级**：同日期手动 > 自动；只影响此后新记录，历史 `event.fx` 不变。
- 自动记录不可删，手动可删。

### 6.2 邮箱服务器配置 + 测试
- 字段：SMTP host / port / secure / user / password / from。
- 「测试连通性」按钮：后端建立连接 → 可选发测试信 → 返回结果。
- 密码加密存储；仅管理员可见。

### 6.3 用户管理
- 列表：用户名、邮箱、注册日期、最近登录日期、状态。
- 操作：**禁用/启用**、**重置密码**（生成临时密码或发重置邮件）。
- 禁用后：登录被拒 + 已发 token 失效。

### 7.4 报表口径
- **主口径：已实现**（股票卖出实盈 + 分红 + 理财/债/基金利息），无需额外输入。
- **含浮动**（可选）：`当月含浮动 = 当月已实现 + (本月末持仓市值 − 上月末 − 当月证券净投入)`；无快照月份标"未记快照"。
- **净投入**按 `event` 的买/卖/投入/赎回计算（v5 起含期初建仓 opening）。
- **出入金**不计入月度浮动（快照为持仓市值），但计入**账户现金**与**累计投入**，并作为 **XIRR 的唯一外部现金流**。

## 9. 部署（Docker）

```yaml
# docker-compose.yml
services:
  app:
    build: .
    ports: ["8080:8080"]
    volumes:
      - ./data:/app/data          # SQLite + 备份持久化
      - ./backups:/app/backups
    environment:
      - JWT_SECRET=change_me
      - FX_SOURCE_URL=https://api.frankfurter.app/latest?from=USD&to=CNY
      - FX_FALLBACK_URL=https://open.er-api.com/v6/latest/USD
      - FX_SYNC_CRON=0 8 * * *
      - SMTP_HOST= SMTP_PORT= SMTP_USER= SMTP_PASS= SMTP_FROM=
    restart: unless-stopped
```

- 首次启动自动建表 + 初始化 admin 账号（env 提供或首启向导）。
- `./data/invest.db` 挂宿主机，容器重建不丢数据。
- JSON 导出 `GET /api/export`；导入前自动备份到 `data/backups/`。

## 11. 给开发模型的施工顺序（10 步）

1. **脚手架**：`docker-compose` + Node 服务 + Vue3(Vite) 前端；SQLite 建表 + 初始化 admin。
2. **鉴权**：注册/双方式登录/JWT 中间件/禁用拦截。
3. **CRUD**：账户、资产、事件、汇率、快照、基准、出入金、定投的 REST。
4. **移植引擎**：把 `server/calc.js` 原样接入后端（纯函数，无依赖）；`node calc.test.js` 必须 **49/49 通过**。
5. **计算接口**：`summary/performance/benchmark/allocation/concentration/tax/alerts/reports`。
6. **前端框架**：路由 + 布局 + 登录态；KPI 卡与持仓看板。
7. **录入闭环**：事件录入弹窗（按类型切字段）+ 除权除息提醒 + 现价维护。
8. **决策页**：绩效、配置、风险、税务、定投、出入金六页 + ECharts 图表。
9. **管理后台**：汇率、邮箱服务器（含测试）、用户管理。
10. **数据与定时**：导出/导入、快照、cron 任务、Docker 打包验收。
